

<h1>Project Title: Blog Website </h1>

<h3>Description:</h3>

This is a personal blog website developed using **HTML**, **CSS**, and **JavaScript**, designed to share articles and insights in a clean, user-friendly layout. The website is fully responsive and features a modern **Dark Mode** toggle to enhance user experience, especially during nighttime reading.

<h3>Key Features:</h3>

- **Responsive Design:** Optimized for all devices including desktops, tablets, and mobile phones.  
- **Dark Mode:** A user-friendly dark/light theme toggle, implemented using JavaScript and CSS variables.  
- **Clean Layout:** Minimal and elegant blog layout focused on readability.  
- **Navigation Bar:** Easy navigation with smooth scrolling to different sections.  
- **Blog Post Section:** Organized articles with featured images, titles, and content previews.  
- **Interactive Elements:** Hover effects and transitions for buttons and links to improve UI/UX.  
- **Contact Section:** A basic contact form for reader engagement and feedback.

<h3>Technologies Used:</h3>

- **HTML:** Structured content including headers, paragraphs, images, and links.  
- **CSS:** Styled the overall layout, colors, fonts, and implemented dark mode using CSS custom properties.  
- **JavaScript:** Handled the dark mode toggle, interactive features, and form behavior.
